
# Elite Cuts 💈

Elite Cuts is a modern barbershop website designed to showcase services, attract clients, and provide an easy way for customers to explore hairstyles, pricing, and booking options.

## 🚀 Features

- Clean and responsive landing page
- Services section (haircuts, beard grooming, styling, etc.)
- Gallery for showcasing hairstyles
- Contact/booking section for appointments
- Mobile-friendly design
